🔗 Démo en ligne : [portfolio.saikoon.ch](https://portfolio.saikoon.ch)

## ✨ Fonctionnalités principales
1. **À propos** - Une section dédiée à mieux comprendre qui je suis. Dessus, je me présente et décris mes motivations dans la vie.

2. **Compétences** - Mise en avant des technologies et outils que je maîtrise et utilise au quotidien.

3. **Parcours** - Ligne du temps interactive retraçant mon parcours éducatif et professionnel, mettant en avant les étapes clés de mon évolution.

4. **Projets** - Showcase de mes réalisations les plus marquantes avec description, stack utilisée, et liens vers les démos ou dépôts GitHub si disponibles.

5. **Contact** - Formulaire de contact simple et direct, avec intégration possible d'un service de mail ou redirection.

6. **Multilingue** - Le contenu du site est disponible en plusieurs langues grâce à `vue-i18n`, permettant de s'adresser à un public international.

7. **Animations** - GSAP est utilisé pour apporter des transitions et animations dynamiques et engageantes.

## 🚀 Installation et lancement en local
Cloner le dépôt :
```
git clone https://github.com/maiscommentz/portfolio-2025.git maiscommentz-portfolio
cd maiscommentz-portfolio
```

Installer les dépendances et lancer en mode développement :
```
npm install
npm run dev
```

## 🔄 Intégration et déploiement continu (CI/CD)
Le projet utilise GitHub Actions pour automatiser les tâches liées au développement et au déploiement. Voici les grandes lignes du pipeline CI/CD :

- **Linting** : à chaque push ou pull request sur la  branche main, le code est automatiquement analysé avec ESLint.

- **Déploiement** :  la version optimisée du site est générée automatiquement et une fois validé, le site est déployé dans le vaste monde du web.

Ce processus garantit une mise en production rapide, fiable et sans manipulation manuelle.
